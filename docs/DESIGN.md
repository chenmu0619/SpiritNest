# 灵栖 Spirit Perch 产品设计

> 版本：0.1.0  
> 状态：按当前实现写定  
> 中文名：灵栖　英文名：Spirit Perch  
> 工程名：`SpiritNest`（仓库、程序集、exe、`%AppData%\SpiritNest`）  
> 交互见 [INTERACTION.md](INTERACTION.md)，视觉见 [../DESIGN_SYSTEM.md](../DESIGN_SYSTEM.md)

## 1. 定位

屏幕顶部居中的灵动岛。平时只占一条，悬停展开面板，用来打开已收纳的快捷方式和网址。

它不是悬浮球，不吸附边缘，不能拖走，也不做文件管理器。


| 做            | 不做                   |
| ------------ | -------------------- |
| 收起为灵动岛或极简细条  | 悬浮球、隐边、贴边面板          |
| 悬停展开、离开收起    | 点击钉住、拖动改位置           |
| 按页面收纳入口      | 多个岛、多坞               |
| 拖入、还原到原路径    | 未确认就清空桌面             |
| 实色碳黑岛 + 奶白设置 | 毛玻璃、跟随系统主题           |
| 单实例 + 托盘常驻   | 第二实例唤醒或展开面板          |
| Windows 安装包  | 跨平台、绿色版 / MSIX 作为主交付 |


目标用户：桌面快捷方式太多，希望平时干净、用时能马上打开的 Windows 用户。

## 2. 形态

```
托盘：开机启动 · 极简模式 · 设置 · 退出
        │
灵动岛（置顶，贴工作区顶边水平居中，不可拖）
        │  悬停
        ▼
展开面板：顶栏 + 当前页图标 / 搜索 / 天气
```

只有灵动岛宿主置顶。设置、网址编辑、搜索引擎编辑、确认框都不置顶。

再次启动已在运行的程序：直接退出，不发激活、不展开面板。托盘双击同样不做展开。没有实例时，启动只显示收起的岛。

全屏游戏或影音占据前台时隐藏岛和面板（默认开）。普通最大化窗口不隐藏。托盘仍在。回到窗口模式后按原状态再显示。

显示变化时，岛留在当前所在显示器工作区的顶部正中，不记吸附边，也不在副屏接回时自动跳屏。

## 3. 收纳



### 3.1 放什么


| 类型                     | 处理                                          |
| ---------------------- | ------------------------------------------- |
| 用户桌面上的 `.lnk` / `.url` | 迁入 `%AppData%\SpiritNest\items\`，记下原目录和原文件名 |
| 用户桌面上的 `.exe` 等可执行文件   | 同样可迁入                                       |
| 安装目录里的程序               | 只建引用，不移动原文件                                 |
| 网址                     | 在页面里添加，保存地址与图标                              |


不把任意文档或文件夹当作一等收纳对象。拖入不支持的类型则忽略。

只认用户桌面（`FOLDERID_Desktop`，含 OneDrive 或重定向后的真实路径）。不扫描公用桌面。实现里不手写拼接 `Desktop` 路径。

### 3.2 怎么放进去

在 **设置 → 页面管理** 里，把文件拖到某个页面。落在该页，并记录原路径。

也可以在页面空白处右键「添加网址」。地址框失焦或回车时，空着的名称和图标会按站点首页自动填写；点图标可改成自己的图，右键图标可清除。

搜索引擎同样：添加或编辑时，未手改过的名称和图标会按站点自动填写；点图标上传，右键清除。地址模板用 `{word}`，`{q}` 仍可用。列表顺序就是优先级，第一个启用的引擎是默认引擎。

### 3.3 还原和删除


| 操作           | 结果                                             |
| ------------ | ---------------------------------------------- |
| 从页面把图标拖回用户桌面 | 按原路径还原，然后从库里去掉                                 |
| 在页面管理里删除     | 先问是否还原到原来的位置。还原则写回原路径；不还原则只从库中移除迁入文件的去留按当次确认处理 |


原路径已有同名文件时自动改名。原目录不可用时回到当前用户桌面并提示。

卸载界面只有一页：勾选「还原快捷方式」（默认不勾）和「保留用户数据」（默认勾选），按钮是「确定卸载」和「取消」。取消则什么都不做。确定后，勾了还原的，只把从桌面或文件夹收进来的快捷方式和网址文件写回原路径；在设置里添加的网址不还原。未勾选保留数据时删除 `%AppData%\SpiritPerch`。同时删除安装版登录任务 `SpiritPerch\Autostart`、旧任务 `SpiritNest\Autostart`，以及 Run 里的 `SpiritPerch` / `SpiritNest`。不删除开发版任务 `SpiritPerchDev\Autostart`。

### 3.4 失效

目标不存在或快捷方式无法解析时，图标变淡，工具提示带「已失效」，单击不启动。检测在启动时刷新。清理方式是在页面管理里删掉该项，而不是单独的「一键清理」按钮。

## 4. 页面

页面即分类。可添加、改名、拖动排序、删除。每页有「展示」开关：关掉后，展开面板的翻页里不出现该页，设置里仍在。

面板只显示已展示页面里的项，按 `sortOrder` 排列。点图标启动；若目标进程已在，则转到已有窗口。

## 5. 数据

```
%AppData%\SpiritNest\
  settings.json
  library.json
  items\{categoryId}\
  cache\icons\
```

`settings.json` 里和当前产品有关的字段：


| 字段                         | 含义                                                                                                                                                          | 默认              |
| -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------- |
| `ExpandDelayMs`            | 悬停多久后展开                                                                                                                                                     | 240             |
| `CollapseDelayMs`          | 离开多久后收起                                                                                                                                                     | 200             |
| `MinimalNotch`             | 极简细条                                                                                                                                                        | 关               |
| `AnimationDurationMs`      | 过渡时长，100–2000，步进 50                                                                                                                                         | 360             |
| `EnablePanelAnimation`     | 是否播放过渡                                                                                                                                                      | 开               |
| `HideOnFullscreen`         | 全屏时隐藏                                                                                                                                                       | 开               |
| `StartWithWindows`         | 开机启动。安装版任务 `SpiritPerch\Autostart`，开发版任务 `SpiritPerchDev\Autostart`，都无延迟。关：只删除自己的任务。安装版还会删掉旧任务 `SpiritNest\Autostart` 和 Run 里的 `SpiritPerch` / `SpiritNest` | 关               |
| `ShowWeather`              | 岛和面板是否显示天气                                                                                                                                                  | 开               |
| `SearchWeatherIdleSeconds` | 搜索/天气无操作后回到图标                                                                                                                                               | 10（可调 3–60）     |
| `PreferredBrowserPath`     | 搜索用的浏览器，空为系统默认                                                                                                                                              | 空               |
| `SearchEngines`            | 引擎列表（顺序即优先级）                                                                                                                                                | 必应、百度、Google、搜狗 |
| `AccentColor`              | 强调色                                                                                                                                                         | `#4F9DFF`       |


`ThemeMode` 仍留在文件里，界面不再提供浅色/深色切换。配色固定为碳黑岛和奶白其余界面。

`library.json`：

```text
categories[]: id, name, sortOrder, visible
items[]:
  id, categoryId, displayName
  itemKind, storageMode
  storedPath, targetPath
  originalDirectory, originalFileName
  source, isBroken, brokenReason
  iconCacheKey, sortOrder, lastLaunchedAt
```

旧数据里若仍有 `ItemKind = Widget` 的条目，面板不展示，也不当成失效文件。

图标在首次解析后写入 `cache\icons\`，避免展开时同步抽取 Shell 图标。

## 6. 技术约束

- C# + WPF，.NET 8。入口 `src/SpiritNest.App/`。
- 一个宿主窗口切换收起与展开，而不是球窗口加面板窗口。
- 透明分层窗口。轮廓用填充几何画在透明底上，圆角才能和桌面抗锯齿。过渡中不缩小这个窗口，否则会闪一帧白。
- 单实例：互斥量 `Local\SpiritNest.SingleInstance.Mutex.v3`，管道 `SpiritNest.SingleInstance.Pipe.v3`。管道仍接受 `exit`，供发布脚本优雅退出。
- 托盘使用 Hardcodet.NotifyIcon。关机或注销时必须先卸托盘再退出，避免拖住关机。
- 默认不要管理员权限。
- 版本号只写在仓库根目录的 `version.txt`。程序版本、关于页和安装包都引用它，当前是 **0.1.0**。



## 7. 发布


| 方式                                        | 作用                                                       |
| ----------------------------------------- | -------------------------------------------------------- |
| `dotnet run --project src\SpiritNest.App` | 开发运行，输出在 `bin\`                                          |
| `_pub.ps1`                                | 优雅退出后自包含发布到 `run\`，并启动。桌面「灵栖 Dev」指向这里                    |
| `installer/build-setup.ps1`               | 发布到 `dist\publish` 并打出 `dist\SpiritNest-Setup-0.1.0.exe` |


不要在进程仍占用 `run\` 时覆盖发布，也不要强杀 `SpiritNest.exe`。
