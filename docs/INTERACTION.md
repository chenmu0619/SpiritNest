# 灵栖交互说明

> 版本：0.1.0  
> 范围：灵动岛、展开面板、托盘、设置  
> 产品决策见 [DESIGN.md](DESIGN.md)，视觉数值见 [../DESIGN_SYSTEM.md](../DESIGN_SYSTEM.md)

## 1. 表面

| 表面 | 做什么 | 置顶 |
|------|--------|------|
| 灵动岛宿主 | 收起的岛或细条，以及展开后的面板 | 是 |
| 设置 | 通用、页面管理、搜索和天气、关于 | 否 |
| 网址 / 搜索引擎编辑、确认框 | 添加与修改 | 否 |
| 托盘 | 开机启动、极简、设置、退出 | — |

宿主不进任务栏，不能拖，不能改大小。贴在所在显示器工作区的顶边正中。岛和面板以外的区域点击穿透到桌面。

## 2. 状态

```
极简细条 ──悬停──► 面板
正常灵动岛 ─悬停─► 面板 ─顶栏─► 搜索或天气 ─返回或超时─► 图标页
                └─离开─► 回到进入前的收起态
```

同一时刻只有一个收起态：正常岛或极简细条，由「极简模式」决定。展开后再收起，回到当前开关对应的那个收起态。

### 2.1 正常灵动岛

宽 136，高 28，底边圆角 14。左温度，中双眼（左眼时、右眼分），右天气。眼睛会眨眼，空闲时眼珠小幅移动。关掉「显示天气」后，左右不显示温度和天气，眼睛仍在正中。

### 2.2 极简细条

宽 128，高 5 的胶囊，整体在顶边下方 5 DIP。不是把岛缩小。细条上方的缝不挡桌面右键。

### 2.3 展开面板

底边圆角 18。宽度固定为 6 个图标槽，不随本页图标多少改变。高度随内容：图标、搜索、天气各自不同。

顶栏从左到右：当前页面名（搜索页为「搜索」，天气页为「天气」）、搜索、天气与温度、`周X yyyy-MM-dd HH:mm`、设置。

## 3. 悬停展开与离开收起

| 时机 | 行为 |
|------|------|
| 指针进入岛或细条 | 停留 **240ms** 后开始展开 |
| 指针离开岛∪面板 | **200ms** 后收起 |
| 展开过程中指针已离开，并在岛外停留满 200ms | 从**当前大小**开始收起，不先放到最大 |
| 展开刚结束时指针不在岛上 | 立刻进入收起，不保持打开 |
| 搜索框正在输入，或搜索引擎弹出层开着 | 暂不因离开而收起 |

过渡默认 360ms，慢—快—慢（前 30% 加速，后 30% 刹车）。设置里的「过渡动画时长」同时作用于展开/收起和搜索、天气切换。过渡中窗口外框不缩小，避免闪白。

桌面快捷方式或再次启动：没有进程时只打开收起态；已有进程时不做任何事，包括不展开。托盘双击不展开。

## 4. 面板里的图标

只列出「展示」打开的页面。左右圆钮或底部圆点换页。圆点悬停可见页面名。

| 本页个数 | 排布 |
|----------|------|
| 0 | 空网格 |
| 1–5 | 一行，居中 |
| 6–12 | 两行均分 |
| 13 及以上 | 每行 6 个，多出的用滚轮 |

单击有效图标：目标已在运行则切到该窗口，否则启动。启动过程中图标变淡。失效项更淡，不能点。

面板上没有右键菜单。增删、改名、排序、拖入都在设置的页面管理里。

## 5. 搜索和天气

**搜索：** 顶栏搜索进入。引擎按钮切换已启用的引擎（列表顺序优先，第一个启用的为默认）。Enter 用所选引擎打开结果；浏览器路径为空时用系统默认。无操作 **10 秒**（设置 3–60 秒）或点返回，回到图标页。

**天气：** 顶栏天气进入。今日概况，以及从明天起 6 天。同一套无操作超时。设置里关掉天气后，岛上不显示温度与天气，顶栏也不再进入天气页。

输入、切换引擎会重置无操作计时。

## 6. 托盘

| 项 | 行为 |
|----|------|
| 开机启动 | 安装版任务 `SpiritPerch\Autostart`，开发版任务 `SpiritPerchDev\Autostart`。开：只写自己的任务。关：只删自己的任务 |
| 极简模式 | 与设置「极简模式」同一开关。展开中的面板会收到对应的收起形态 |
| 设置 | 打开设置；已开则激活 |
| 退出 | 结束进程并卸托盘 |

没有「关于」。关于在设置里。没有「显示/隐藏岛」。要退出只能点「退出」。

## 7. 设置

左栏四项，右栏对应内容。窗口不置顶。

### 7.1 通用

开机启动、极简模式、全屏时隐藏、过渡动画时长（100–2000ms，步进 50，右侧显示当前毫秒）。

### 7.2 页面管理

- 添加页面、改名、拖动页面排序、删除页面
- 「展示」控制该页是否出现在面板翻页中
- 页内图标可拖动改顺序，也可拖到别的页
- 从资源管理器把文件拖进某一页即收纳，并记住原路径
- 把图标拖出到用户桌面即还原到原路径
- 图标右键「删除」；空白处右键「添加网址」
- 删除前询问是否还原到原来的位置
- 网址编辑：地址与名称。空名称和空图标会在离开地址框时按网站自动填写。点图标上传，右键图标清除

### 7.3 搜索和天气

- 默认浏览器路径，空表示系统默认；可浏览选择
- 无操作返回秒数
- 显示天气
- 搜索引擎列表可排序、启用。添加一行时自动取站点名称和图标；手改过的名称或图标不会被覆盖。点图标上传，右键清除。模板占位符 `{word}` 或 `{q}`

### 7.4 关于

产品名、版本 **0.1.0**、数据目录、打开数据文件夹。

## 8. 全屏

前台窗口盖住工作区（游戏、全屏影音）时立刻收起并隐藏宿主。桌面、任务栏和普通最大化窗口不算。开关在「全屏时隐藏」，默认开。退出全屏后恢复隐藏前的收起态。
