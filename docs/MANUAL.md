# 灵栖产品说明和使用手册

版本 0.1.0。本文面向安装后的灵栖。

## 1. 产品说明

灵栖是放在屏幕顶部正中的灵动岛。平时只有一条：左边温度，中间用两只眼睛表示时和分，右边天气。鼠标移上去，展开成快捷方式面板，用来打开已经收进来的程序和网址。指针离开后收回成岛。

它解决的是桌面图标太多。常用入口放进灵栖，桌面可以空出来；要用的时候从屏幕顶上打开，不用先找图标。

灵栖不做这些事：

- 不是悬浮球，不能拖走，也不贴在屏幕左右边缘
- 不管理普通文件和文件夹
- 不会未经确认就清空桌面
- 不随系统切换浅色或深色。岛是碳黑色，设置是奶白色

程序文件是 `SpiritPerch.exe`，默认装在 `C:\Program Files\SpiritPerch`。界面上的名字是灵栖。

## 2. 装好之后

安装时可以勾选：

- **创建桌面快捷方式**，默认不勾
- **开机时启动灵栖**，默认勾选

装完后，屏幕顶部正中出现灵动岛，任务栏右下角有托盘图标。灵栖不出现在任务栏里。

已经在运行时再打开一次，不会出现第二个岛，也不会把面板展开。

## 3. 灵动岛

岛贴在当前这台显示器工作区的顶边正中，一直在最前，不能拖，不能改大小。岛和面板以外的空白处点下去，会点到后面的窗口。

| 样子 | 什么时候 |
|------|----------|
| 正常岛 | 默认。温度、双眼时钟、天气 |
| 极简细条 | 设置或托盘里打开「极简模式」。顶边下一条细胶囊，不挡桌面右键 |
| 展开面板 | 指针在岛或细条上停留约 0.24 秒 |

眼睛会眨眼，空闲时眼珠会动一点。关掉「显示天气」后，岛上不再显示温度和天气，时钟仍在。

指针离开岛和面板约 0.2 秒后收回。正在搜索框里打字，或搜索引擎菜单开着时，不会因为指针离开就收起。展开和收回的动画默认约 0.36 秒，可在设置里改。

## 4. 展开面板

顶栏从左到右：当前页面名、搜索、天气和温度、星期与日期时间、设置。

下面是这一页的图标。左右圆钮或底部圆点换页。圆点上悬停可以看到页面名。只有「展示」打开的页面会出现在这里。

| 这一页有几个 | 怎么排 |
|--------------|--------|
| 1–5 个 | 一行 |
| 6–12 个 | 两行 |
| 13 个以上 | 每行 6 个，多的用滚轮 |

单击一个有效图标：程序已经开着就切到它的窗口，否则启动。启动过程中这个图标变淡，不能连点。目标已经不在或快捷方式打不开时，图标更淡，提示「已失效」，点了不会启动。

面板上没有右键菜单。添加、删除、排序都在设置的「页面管理」里。

## 5. 把快捷方式收进来

打开 **托盘 → 设置 → 页面管理**。

1. 需要新分类时，点「添加页面」，再改名。拖动页面可以改顺序。「展示」关掉后，这一页不出现在展开面板里，设置里还在。
2. 从资源管理器或桌面，把快捷方式、网址文件或程序拖进某一页。灵栖会记下原来的位置。
3. 页里的图标可以拖动改顺序，也可以拖到另一页。
4. 空白处右键「添加网址」。地址写好后，空着的名称和图标会按网站自动填上。点图标可以换成自己的图，右键图标可以清除。

拖进来的是入口，不是把整个文件夹收进灵栖。不支持的文件类型会忽略。

### 还原和删除

- 在页面管理里把图标拖回桌面：按收进来之前的位置放回去，并从灵栖去掉。
- 在图标上右键「删除」：先问要不要还原到原来的位置。还原就写回原路径；不还原就只从灵栖去掉。
- 原来的位置已经有同名文件时，会自动改名。原来的文件夹没了，就放回当前桌面并提示。

在设置里添加的网址没有原来的文件，删除时不会写回桌面。

失效的图标没有单独的「一键清理」。在页面管理里删掉即可。

## 6. 搜索和天气

**搜索。** 展开后面板顶栏点搜索。用已启用的搜索引擎，列表里第一个启用的是默认。Enter 打开搜索结果。设置里没指定浏览器时，用系统默认浏览器。大约 10 秒没有操作，或点返回，回到图标页。这个秒数可在 3 到 60 秒之间改。

**天气。** 顶栏点天气，看今天和接下来 6 天。同样会在无操作后回到图标页。关掉「显示天气」后，岛上和顶栏都不再进入天气。

## 7. 设置

托盘里点「设置」，或在展开面板顶栏点齿轮。设置窗口不置顶。左栏四页。

### 通用

| 项 | 作用 |
|----|------|
| 开机启动 | 登录时启动灵栖。安装版写入计划任务 `SpiritPerch\Autostart`，登录后马上启动，不等资源管理器那一段延迟。关掉就删掉这个任务 |
| 极简模式 | 收起时用细条，不用完整的岛。和托盘里的「极简模式」是同一个开关 |
| 浏览器极简 | 默认关。打开后，同一台显示器上的浏览器被最大化时，岛暂时变成细条，避免挡住标签。浏览器不再最大化就恢复。这不改变「极简模式」本身的开关 |
| 全屏时隐藏 | 默认开。游戏或全屏视频盖住屏幕时，岛和面板立刻隐藏。普通最大化、桌面和任务栏不算全屏。退出全屏后恢复 |
| 过渡动画时长 | 100–2000 毫秒，每步 50。展开、收回，以及进出搜索、天气，都用这个时长 |

### 页面管理

添加、改名、排序、删除页面，以及第 5 节的拖入、拖出和删除。

### 搜索和天气

- **默认浏览器**：空着就是系统默认，也可以点「浏览」指定一个程序
- **无操作返回**：搜索和天气闲置多久后回到图标
- **显示天气**
- **搜索引擎**：可排序、可单独启用。添加时会尽量填上站点名称和图标。地址里用 `{word}` 表示搜索词，`{q}` 也可以。点图标上传，右键清除

### 关于

显示产品名灵栖、版本号、安装目录和数据目录。可以打开安装目录和数据文件夹。

安装版数据在：

`C:\Users\<用户名>\AppData\Roaming\SpiritPerch`

里面有设置、收藏库、收进来的快捷方式和图标缓存。

## 8. 托盘

右下角灵栖图标，右键：

| 项 | 作用 |
|----|------|
| 开机启动 | 与设置里同一开关 |
| 极简模式 | 与设置里同一开关 |
| 设置 | 打开设置。已经开着就切到那个窗口 |
| 退出 | 结束灵栖并去掉托盘图标 |

双击托盘图标不会展开面板。没有单独的「隐藏岛」。要结束程序，用「退出」。

## 9. 卸载

在 Windows 的应用列表里卸载灵栖。卸载只有一页：

- **还原快捷方式**：默认不勾。勾选后，只把从桌面或文件夹收进来的项目写回原来的位置。在设置里添加的网址不还原
- **保留用户数据**：默认勾选。取消勾选会删除 `%AppData%\SpiritPerch`
- **确定卸载** 才开始。**取消** 什么都不做

无论是否保留数据，都会去掉开机启动：计划任务 `SpiritPerch\Autostart`，以及旧的启动项。开发版如果另有自己的任务，卸载安装版不会删它。

卸载时如果灵栖还开着，同一页上会提示，并且要等程序退出后才能继续。
